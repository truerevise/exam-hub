⚡ Daily Live Test Access

Control how many times students can attempt each Daily Live Test. Default is 1 attempt. You can override the limit for everyone, a student group, or an individual student.

🌍 All Students

Set the default total attempts allowed for every student for this test.

👥 Group Access

Students need a group field in their student document. Example: BCom-2, UGCNET, PremiumBatch.

👤 Individual Student

Give one student a different attempt limit. This overrides the group and all-student limit.

🧹 Reset / Start Again

Use the individual reset above when a student needs to start the selected Daily Live Test again from attempt 1. It removes that student's attempt counter, results for this live test and leaderboard entry.
