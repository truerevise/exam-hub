📥 Bulk Import Questions
Import hundreds of MCQs from a CSV or paste them from a spreadsheet. Preview and validate everything before saving.

1. Import settings

Choose an existing exam or create a new exam name.
Subjects are filtered by the selected exam.

2. Add your data

Recommended: Use the downloadable CSV template. Required columns: question, A, B, C, D, answer. Optional bilingual fields: questionTe, ATe, BTe, CTe, DTe, explanationTe. Also supports questionNumber for serial numbering. English remains the original source; supplied Telugu is shown when Telugu mode is selected. CSV fields may contain commas when quoted correctly.
Works with comma-separated CSV, tab-separated data copied directly from Excel, and quoted cells containing commas.
